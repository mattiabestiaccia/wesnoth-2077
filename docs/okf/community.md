# Canali ufficiali

| Canale | URL | Uso |
|--------|-----|-----|
| Forum | https://forums.wesnoth.org/ | Discussioni generali, add-on, arte |
| Discord | https://discord.gg/battleforwesnoth | Chat in tempo reale |
| IRC (Libera.Chat) | `#wesnoth`, `#wesnoth-dev`, `#wesnoth-umc-dev` | Sviluppo e add-on |
| Mastodon | https://fosstodon.org/@wesnoth | Aggiornamenti progetto |
| Steam forums | https://steamcommunity.com/app/599390/discussions/ | Giocatori Steam |
| Wiki | https://wiki.wesnoth.org/ | Documentazione estesa |

# Sviluppo

Per contribuire al codice o alla documentazione, vedere [Contributing](/development/contributing.md). Per domande tecniche sul motore, i canali `#wesnoth-dev` su Discord/IRC sono i più adatti.

# Donazioni

Donazioni tramite [SPI](https://www.spi-inc.org/projects/wesnoth/), [Liberapay](https://liberapay.com/Wesnoth) o itch.io. I fondi coprono server e commissioni artistiche.
