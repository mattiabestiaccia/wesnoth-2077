# Codice sorgente

Tutto il codice sorgente è rilasciato sotto **GNU GPL v2+**. Il file completo è in [`COPYING`](../../COPYING).

# Arte e musica

La maggior parte di arte e musica esistente è sotto GPL v2+. Le **nuove contribuzioni** sono rilasciate sotto **Creative Commons BY-SA v4.0**.

# Dettagli

Per informazioni complete su copyright e attribuzioni, consultare la wiki ufficiale e il file `copyrights.csv` nel repository.
